## Stack

- **API:** Go
- **Storage:** Postgres, with Redis in front for reads
- **Deployment:** self-hosted Kubernetes (Talos on Proxmox), one physical server
- **Monitoring:** Prometheus metrics in VictoriaMetrics, Grafana dashboards
- **Load testing:** k6
